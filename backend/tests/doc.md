# tests

Unit-Tests (pytest) mit harter Abdeckungsschwelle von 100 % Zeilen und Zweigen. Der Ordnerbau
spiegelt `src/bot/`. Property-based Tests (Hypothesis) liegen neben den Beispieltests und enden
auf `_properties.py`.
